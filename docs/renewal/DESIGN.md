# 確認画面の DESIGN.md(リニューアル案)

ディレクター1人が、1案件 1,000〜10,000 ページを1ページずつ目視で確認し、FTP に上げる前の HTML を確定する画面の視覚規則である。
画面を作る前にこの規則を決め、作ったあとはこの規則に合っているかで見直す。

## 利用の前提

- 使うのはディレクターだけ。1日5時間、1ページ平均およそ2分で流す(10,000 ページを60営業日で終える場合)。
- 一括処理がページごとに候補を作り、目視の深さを3段階に分けてある。段階0は開かない、段階1は差分を見て採用する、段階2は読んで判断する。
- 主な操作はキーボードで行う。マウスでもすべて操作できる。

## 骨格

- 3つの列を固定する。左が待ち行列(ページの一覧)、中央が差分、右が候補。画面全体はスクロールさせず、各列が自分の中でスクロールする。
- 上端に案件の帯(案件名、取込回、段階ごとの残り、今日の処理数、推定の残り日数)。下端に確定の帯(このページの未判断の数、確定して次へ)。
- 浮いて重なるパネルは使わない。案内は確定の帯の中に1行で出す。
- 1280×800 で3列が収まること。1100px 未満では候補の列を差分の下に回す。

## 色の役割

色は意味にだけ使う。役割は次の6つに限る。

| 役割 | 色 | 使う場所 |
| --- | --- | --- |
| 修正前(削除) | コーラル `#b4232c`、背景 `#fde8e7` | 差分の取り消し部分 |
| 修正後(追加) | ティール `#0f6b5c`、背景 `#e0f4ef` | 差分の追加部分、採用した候補の印 |
| 要確認 | アンバー `#8a5a00`、背景 `#fff3d6` | 要確認の候補、後回しにしたページ |
| 構造のタグ | 紫 `#5b3fa0`、背景 `#efeafb` | `<h2>` `<table>` のようなタグの札 |
| 選択 | 紺 `#1f3f8f` の 3px の左枠 | 待ち行列の選択行、選択中の候補、差分の該当箇所 |
| 基調 | 文字 `#1b2230`、補助 `#4a5468`、区切り線 `#d3d8e2`、操作できる部品の枠 `#8a93a6`、面 `#ffffff`、地 `#f4f5f7` | それ以外すべて |

- 選択は色の面で塗らず、左枠と位置で示す。同じ候補を、右の一覧と中央の差分の両方で同じ左枠で示す。
- 決定の状態(採用、却下、編集して採用、後回し)は、色に加えて文字とアイコンで示す。色だけに頼らない。
- 文字と背景のコントラストは 4.5:1 以上、ボタンや入力欄など操作できる部品の枠は 3:1 以上にする(`#8a93a6` は白に対して 3.09:1)。面を区切るだけの線は、この限りでない。

## 書体

- 画面の文字は `"BIZ UDPGothic", "Yu Gothic UI", "Meiryo", sans-serif`。
- HTML、タグの札、移行管理 ID は等幅 `"BIZ UDGothic", Consolas, monospace`。
- 明朝は使わない。行政文書らしさは、余白と罫線の整い方で出す。
- 大きさは 4 段に限る。12px(補助)、14px(本文)、16px(列の見出し)、18px(ページ題名)。

## 形

- 角丸は 4px だけ。影は使わない。面の区切りは 1px の線で示す。
- 余白は 4px の倍数(4、8、12、16、24)。
- 動きは状態が変わったことを示す 120ms のものだけにする。`prefers-reduced-motion` では止める。背景の飾りの動きは使わない。

## 部品

- **待ち行列の行**: 移行管理 ID(等幅)、ページ題名、段階の札、難易度、候補数、状態のアイコン。1行の高さは 2 行分に固定する。
- **段階の札**: 「段階0 自動」「段階1 一目」「段階2 読む」。段階2は太字にする。色は基調の色だけ。
- **候補のカード**: タグの札、ルールの名前、修正前と修正後の短い抜き出し、根拠(KB のルール名)、操作(採用、却下、編集、後回し)。カードの高さは中身に合わせ、操作は常に同じ位置に置く。
- **差分**: 段落ごとに、取り消し(コーラル、取り消し線)と追加(ティール、下線)を同じ行に並べる。候補の番号を差分の該当箇所の左に出す。
- **確定の帯**: 未判断の候補があるあいだは「確定して次へ」を押せない。押せない理由を帯の中に書く。

## キーボード

| キー | 動き |
| --- | --- |
| J / K | 次の候補 / 前の候補 |
| A | 採用 |
| R | 却下 |
| E | 編集して採用 |
| L | 後回し(要確認) |
| Shift+A | このルールの候補を、案件の全ページで採用する |
| Enter | このページを確定して次のページへ |
| N / P | 次のページ / 前のページ(確定しない) |
| ? | キーの一覧 |

## してはいけないこと

- 色を新しい役割に足す。足したくなったら、文字かアイコンで表せないかを先に考える。
- 浮いて重なるパネル、背景の飾りの動き、ホバーで浮くボタン。
- 開発者向けの表示(ルールの ID、ファイル名、内部の状態)を、既定の画面に出す。

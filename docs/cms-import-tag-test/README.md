# CMS 取込試験(許可されるタグと属性の確認)

FTP に置いた HTML を SMART CMS が取り込んだとき、どのタグ、属性、style の指定が残り、どれが消えたり変わったりするかを確かめるための試験ページと照合画面である。
結果は、一括処理が出力する HTML の形(何を残し、何を書き換えるか)を決める根拠にする。

## 背景

2026-10-05 に、取込環境で次のことを確かめた(ユーザーによる試験取込)。

- HTML は断片(html、head、body の無いもの)のままで取り込める。
- 画像と PDF は、旧サイトの絶対 URL のままで取り込まれる。
- `#id` を使ったページ内アンカーは残らない。KB の「ページ内アンカーリンク」(`a11y-migration-kb/rules/link/in-page-anchor.md`)が「原則移行しない」としているのと合う。
- 許可されるタグと属性は、まだ分からない。この試験で確かめる。

## ファイル

| ファイル | 中身 | 取込の失敗 |
| --- | --- | --- |
| `01-text.html` | 見出し、段落、文字の装飾、構造の要素、属性、style の指定(52 項目) | 失敗しない想定 |
| `02-list-table.html` | リストと表(27 項目) | 失敗しない想定 |
| `03-links.html` | リンク、メール、電話、ページ内アンカー(22 項目) | 失敗しない想定 |
| `04-media.html` | 画像、横並び、ファイルのリンク、埋め込み動画(27 項目) | 印を置き換えないと失敗する |
| `05-risky.html` | 相対パス、インラインの SVG、data URI、script、フォーム、機種依存文字など(19 項目) | ページごと失敗することがある |
| `checker.html` | 印の置き換えと、取込前後の照合を行う画面 | ― |

各項目の前には `【T0101】` のような目印の段落がある。
照合画面は、目印から次の目印までを1項目として、取込の前と後を比べる。
CMS がパーツごとに `div` で囲み直しても、目印の文字が残っていれば項目を突き合わせられる。

存在しないファイルの参照や、取込を止めることがある外部リンク(ふるさと納税のサイト、Adobe Reader のダウンロードなど)は、01〜03 に入れていない(`memory/cms-migration-import-failure-patterns.md` 2章)。

## 手順

1. `checker.html` を Chrome で開く。
2. 「1. 準備」に、旧サイトに実在する画像、アイコン、PDF、Excel、Word の絶対 URL と、YouTube の埋め込み URL を入れる。`04-media.html` と `05-risky.html` を選んで「置き換えて保存する」を押す。印を置き換えたファイルがダウンロードされる。
3. 01〜03 と、置き換えた 04、05 を FTP の試験用の置き場に上げる。
4. 移行管理シートの取込データに試験用の行を5行足し、移行元 URL に FTP 上の URL を入れて取り込む。行の他の列は、案件の試験用の行に合わせる。
5. 行ごとに、取込の結果(取込シートの「結果」と「エラー内容」の列)を控える。05 が失敗したら、エラー内容を控えたうえで、怪しい項目を半分ずつ外して取り込み直すと原因を絞れる。
6. 取り込めたページのプレビュー URL を Chrome で開き、Ctrl+S で「ウェブページ、HTML のみ」を選んで保存する。「取り込み範囲プレビュー」の HTML を保存してもよい。
7. `checker.html` の「2. 照合」で、元の試験ページ(手順3で上げたもの)と、手順6で保存した HTML を選んで「照合する」を押す。
8. 「項目ごとの結果」と「タグと属性の残り具合」の CSV を保存する。

## 結果の読み方

| 判定 | 意味 |
| --- | --- |
| そのまま | 元と同じ。 |
| 囲みだけ違う | `div` の囲みを外すと同じ。CMS がパーツの囲みを足した場合など。 |
| 変化あり | タグ、属性、文字のどれかが変わった。「消えたもの」「増えたもの」の列と、元と取込後の HTML を見る。 |
| 消えた | 中身が残っていない。 |
| 目印なし | 取込後の HTML に目印の段落が無い。ページごと取込に失敗したか、保存した範囲に入っていない。 |

「タグと属性の残り具合」は、タグ(`table`)、属性(`th@scope`)、style の指定(`span@style:color`)ごとに、出てくる項目のうち取込後も残った数を示す。
残った割合の低いものから並ぶ。

## 結果の置き場所

保存した CSV と取込後の HTML は、このフォルダの `results/<試験日>/` に置く。
結果をもとに、CMS が受け付けるタグと属性の一覧を `a11y-migration-kb/cms/` に足し、一括処理の出力をそれに合わせる。

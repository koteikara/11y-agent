CMS取込試験の照合

取込試験のページ(01〜05)が、SMART CMS に取り込まれたあとにどう変わったかを、項目ごとに確かめる画面です。ファイルはこの画面の中だけで読み、どこにも送りません。

手順は同じフォルダの README.md にあります。

1. 準備: 印を実在する URL に置き換える

置き換える印と URL

04 と 05 には、画像やファイルの代わりに波かっこ2つで囲んだ印があります。旧サイトに実在する絶対 URL を入れてください。存在しない URL があると、取込はページごと失敗します。


2. 照合: 元の HTML と取込後の HTML を比べる

読み込むファイル



CMS のプレビュー URL を開き、Ctrl+S で「ウェブページ、HTML のみ」を選んで保存したもの。「取り込み範囲プレビュー」の HTML でも構いません。

3. 結果

判定の内訳

判定の意味: 「そのまま」は元と同じ。「囲みだけ違う」は div の囲みを外すと同じ(CMS がパーツの囲みを足した場合など)。「変化あり」はタグ、属性、文字のどれかが変わった。「消えた」は中身が残っていない。「目印なし」は取込後の HTML に目印の段落が無い(ページごと失敗した、または保存した範囲に含まれない)。

タグと属性の残り具合

元の試験ページに出てくるタグ、属性、style の指定ごとに、取込後にも残った項目の数を数えます。「目印なし」の項目は数えません。

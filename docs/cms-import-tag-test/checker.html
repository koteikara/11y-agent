CMS取込試験の照合

取込試験のページ(01〜13)が、SMART CMS に取り込まれたあとにどう変わったかを、項目ごとに確かめる画面です。ファイルはこの画面の中だけで読み、どこにも送りません。

手順は同じフォルダの README.md にあります。

1. 準備: 印を実在する URL に置き換える

置き換える印と URL

試験ページには、旧サイトのページ、画像、ファイルの代わりに波かっこ2つで囲んだ印があります。同じフォルダの test-site/ を試験用の置き場に上げ、その URL を下の「試験用サイトの URL」に入れて「試験用サイトで埋める」を押すと、YouTube 以外の印がすべて埋まります。旧サイトに実在する絶対 URL を1つずつ入れてもかまいません。存在しない URL があると、取込はページごと失敗します。置き換えたファイルは、名前の末尾に -ready を付けて保存します。複数のファイルを続けて保存するとき、Chrome が「複数ファイルのダウンロード」を許可するか尋ねるので、許可してください。



2. 照合: 元の HTML と取込後の HTML を比べる

読み込むファイル



CMS のプレビュー URL を開き、Ctrl+S で「ウェブページ、HTML のみ」を選んで保存したもの。「取り込み範囲プレビュー」の HTML でも構いません。

3. 結果

判定の内訳

判定の意味: 「そのまま」は元と同じ(半角の空白の違いは見ない。全角空白、&nbsp;、pre の中の空白は見る)。「囲みだけ違う」は、元にあったものが何も減っておらず、div、section、article の囲みを外すと同じ(CMS がパーツの囲みを足した場合など)。「変化あり」はタグ、属性、文字のどれかが変わった。「消えた」は中身が残っていない。「目印なし」は取込後の HTML に目印の段落が無い(ページごと失敗した、または保存した範囲に含まれない)。

タグと属性の残り具合

元の試験ページに出てくるタグ、属性、style の指定、特別な空白(&nbsp; と全角空白)ごとに、項目の中での出現数を取込の前と後で比べます。「目印なし」の項目は数えません。

# 必須ルール
ファイルのリンクの扱いは、CMS でファイルのリンクの部品になるか、本文の中にリンクとして残るかで変わる。
- ファイルのリンクの部品(ファイル入力エリアから挿入したもの、コンテンツ取り込みでファイルのリンクだけの段落から作られたもの)では、CMS がファイル種別と容量を自動表示する。表示テキストに含まれるファイル種別(PDF等)や容量は、二重になるので削除する。作業者が CMS で登録するときは、ファイルはテキスト入力エリアではなくファイル入力エリアから挿入する。
- 本文の中に残るファイルのリンク(コンテンツ取り込みで「複数行HTML内素材処理: そのまま」にした案件の、文の中、箇条書きの中、表の中のリンク)では、CMS は種別と容量を表示しない。表示テキストに、ファイル種別と実際の容量を書く。容量は、元の表記を写さず、ファイルの実際の大きさから書く。
- どちらになるかは、案件の取り込みの設定とリンクの置き場所で決まる。判断できないときは、取り込んだあとのページで、種別と容量が二重になっていないか、抜けていないかを確かめる。

# 例
## ケース1: 種別・容量の重複(ファイルのリンクの部品)
```before
出生届（PDF：1,928kbyte）
```
```after
出生届
```
## ケース2: 本文の中に残るファイルのリンク(複数行HTML内素材処理: そのまま)
```before
申請書は<a href="shussei.pdf">出生届の様式</a>を使ってください。
```
```after
申請書は<a href="shussei.pdf">出生届の様式（PDF：1.9MB）</a>を使ってください。
```
ポイント: 表の中の様式の一覧のように、行とファイルの対応を保つためにリンクを本文の中に残す場合は、種別と容量をリンクの文字に入れる。容量はファイルの実際の大きさから書く。

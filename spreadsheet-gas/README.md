# 記録用スプレッドシートのGAS

移行作業の記録用スプレッドシートで使うGoogle Apps Scriptを置く場所である。
以前の案件で使用していたスクリプトをここへ取り込み、3パターン比較検証（通常移行・AI移行・miChecker移行）の記録に合わせて改修していく。

現在置いてあるファイルは、既存スクリプトを貼り付けるための入れ物である。中身は空に近い状態で、そのまま実行しても何も起きない。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | スクリプト本体。既存のGASの内容で上書きする。 |
| `appsscript.json` | Apps Scriptのマニフェスト。タイムゾーンと実行環境（V8）だけを書いてある。 |

Apps Scriptエディタ側でファイルが複数に分かれている場合は、同じファイル名で `.gs` を追加する。
エディタ上の並び順とファイル名を変えないでおくと、後から差分が追いやすい。

## 取り込み手順（既存スクリプトの上書き）

1. Apps Scriptエディタで対象のスクリプトを開く。
2. ファイルごとに中身を全選択してコピーする。
3. このディレクトリの同名ファイルへ貼り付けて上書きする。エディタ側にしか無いファイルは、同じ名前で新規作成する。
4. 「プロジェクトの設定」からマニフェスト（`appsscript.json`）を表示し、その内容で `appsscript.json` を上書きする。

`clasp` を使う場合は、このディレクトリで `clasp clone <スクリプトID>` または `clasp pull` を実行してもよい。
その際に作られる `.clasp.json` にはスクリプトIDが入るため、リポジトリには含めない（`.gitignore` で除外している）。

## 置かないもの

- スクリプトID、スプレッドシートID、APIキーなどの環境固有の値
- 自治体名や作業者名を含む実データ

環境固有の値が必要な場合は、スクリプトプロパティ（`PropertiesService`）から読む形にして、値そのものはリポジトリへ入れない。

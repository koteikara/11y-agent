# 記録用スプレッドシートのGAS

移行作業の記録用スプレッドシートで使うGoogle Apps Script。
シート上で行を選び、サイドバーのタイマーで作業時間を計測して書き込む。

3パターン比較検証（通常移行・AI移行・miChecker移行）に合わせて、
**ツール作業とCMS作業を別々に計測し、合算する**構成になっている。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `Code.gs` | サーバー側。列の解決、計測、シートへの書き込み。 |
| `Index.html` | サイドバーのUI。区間の選択、タイマー表示、操作ボタン。 |
| `appsscript.json` | マニフェスト。 |

## シートの作り方

- シートは**自治体 × 3パターン**で分ける。シート名は自由に付けてよい。
- **見出しは2行目**、データは**3行目**から。
- シート名では対象を判別しない。2行目の見出しに下記の列があるシートを対象とする。
  シートが増えてもスクリプトの設定を変える必要はない。

### 計測に使う見出し

| 見出し | 内容 |
| --- | --- |
| `ツール作業開始` | ツール作業の開始時刻（自動記入） |
| `ツール作業終了` | ツール作業の終了時刻（自動記入） |
| `ツール休憩時間` | ツール作業中の休憩の累計（分、自動加算） |
| `ツール作業時間` | ツール作業の実働（分、自動記入） |
| `CMS作業開始` | CMS作業の開始時刻（自動記入） |
| `CMS作業終了` | CMS作業の終了時刻（自動記入） |
| `CMS休憩時間` | CMS作業中の休憩の累計（分、自動加算） |
| `CMS作業時間` | CMS作業の実働（分、自動記入） |
| `作業時間集計` | ツール作業とCMS作業の合計（分、終了のたびに再計算） |

既存シートの `作業開始` `作業終了` `休憩時間` の3列は、上記の8列に置き換える。
`作業時間集計` は残したまま、両区間の合計として使う。

パターン1（通常移行）のシートは、ツール作業の4列を置かなければよい。
その場合はサイドバーで「CMS作業」だけが選べる状態になる。

### 見出しの扱い

- 見出しの改行・空白（全角含む）は無視して照合する。`ツール\n作業開始` のように改行を入れてよい。
- 列の位置は自由。見出しの文字列で引くため、列を差し込んでも動作する。
- 同じ見出しが複数ある場合は**左端の列**を採用する。
  既存シートの `差戻し内容(ｽﾀｯﾌ宛て)` のように重複した見出しがあるが、計測に使う9つの見出しは重複していないため影響しない。

## 使い方

1. シートを開くとメニューに「⏱️ 作業記録」が出る。「操作パネルを開く」でサイドバーを表示する。
2. 「計測する区間」で**ツール作業**か**CMS作業**を選ぶ。計測中は切り替えられない。
3. 記録する行を選んで**[開始]**を押す。既に記録がある行では、累計再開か新規（上書き）かを選ぶ。
4. 離席時は**[休憩]**、戻ったら**[休憩終了]**。作業を止めるときは**[中断]**、戻ったら**[再開]**。
5. **[終了]**でその区間の実働（総作業ー休憩）を書き込み、あわせて `作業時間集計` に合計を書き込む。
6. 区間を切り替えて同じ行で開始すれば、もう一方を計測できる。合計は終了のたびに計算し直される。

計測状態はユーザープロパティに保持しているため、ブラウザを閉じてもサイドバーを開き直せば復旧する。

## 動作確認

Apps Script上でしか実行できない部分があるため、GASのAPIをモックしてロジックだけを確認している。
確認した内容は次のとおり。

- 2行目の見出しからツール作業・CMS作業・合計の列を解決する
- ツール作業の列が無いシートではCMS作業だけが選べる
- 2行目（見出し行）を選んだまま開始しようとすると拒否する
- ツール作業60分とCMS作業30分を計測すると、合計が90分になる
- 休憩10分を挟んだ60分の作業が50分になる
- 休憩したまま終了しても、その休憩分を差し引いて集計する
- 累計再開が既存の作業時間を起点に加算する（休憩を二重に引かない）
- 新規（上書き）開始で、その区間の終了時刻・休憩時間・作業時間を消してから始める
- 別の行・別の区間で計測中のときに検知する
- 中断と再開をまたいでも作業時間が積み上がる
- 終了時に、このスクリプト以外のユーザープロパティを消さない

## 置かないもの

- スクリプトID、スプレッドシートID、APIキーなどの環境固有の値
- 自治体名や作業者名を含む実データ

`clasp clone` や `clasp pull` で生成される `.clasp.json` はスクリプトIDが入るため、`.gitignore` で除外している。
